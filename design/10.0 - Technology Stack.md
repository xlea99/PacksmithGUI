## 10. Technology Stack

| Component        | Technology                                   |
|------------------|----------------------------------------------|
| GUI framework    | PySide6 (Qt for Python)                      |
| Database         | SQLite3                                      |
| Text editor backbone | Monaco (embedded via QWebEngineView)     |
| Action runtime   | Starlark via `starlark-pyo3`                 |
| File formats     | JSON (registries), TOML (config), SQLite     |
| Python version   | 3.13                                         |
| Forge mod        | Java 17, Minecraft 1.20.1, Forge 47+        |
| Build system     | Gradle (mod), pip/manual (GUI — no build yet)|
