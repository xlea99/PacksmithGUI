### 2.1 Packdump (The Forge Mod)

A Minecraft Forge mod (currently targeting 1.20.1, Forge 47+) that acts as a data
extraction bridge. On world load (or via `/packdump dump`), it serializes the game's
complete state into JSON:

- **Registries** — every registry type (100+ in modded 1.20.1): items, blocks, entities,
  biomes, enchantments, mob effects, sound events, worldgen features, etc. Each gets its
  own file with a sorted `values` array.
- **Localization** — display names for items, blocks, entities, enchantments, and mob
  effects, resolved through the game's language system.
- **Metadata** — timestamp, MC version, Forge version, loader info, complete mod list
  with versions, and a registry manifest.

Output lands in `<gameDir>/packsmith/` as:
```
packsmith/
  meta.json
  registries/
    minecraft_item.json
    minecraft_block.json
    ... (one per registry type)
  attributes/
    localization.json          # one file per locale; see below
```

This section used to say `packdump/`, which nothing ever wrote. The mod defines
`outputDir` (default `"packsmith"`) in its Forge config and the GUI reads
`<mc_path>/packsmith`, so the name is settled by two implementations that already agree —
and is *configurable* on the mod side, which is why the GUI accepts an explicit source
path override rather than hardcoding one.

**Locales.** The mod currently dumps `en_us` only, hardcoded, to a single
`localization.json`. The GUI's model has always been multi-locale, so snapshots it writes
name the locale in the file — `localization.en_us.json`, `localization.de_de.json` — and
locales are discovered by glob rather than assumed. The unsuffixed name is still read, as
both the mod's current output and the layout of every snapshot already archived. **If the
mod grows multi-locale dumping, it should adopt the suffixed name**; that is the only
cross-repo contract here.

One mod-side hazard worth naming: with `overwriteExisting = false`, a re-dump writes
`localization_<timestamp>.json` and leaves the *stale* `localization.json` in place — which
is the one the GUI reads. The default is `true`, so this only bites someone who changed it.

The mod also performs a **world datapack safety check** — if world-specific datapacks
(IDs starting with `file/`) are detected, the dump aborts to prevent contaminated
snapshots.
